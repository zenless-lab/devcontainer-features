# HEASoft (heasoft)

Installs HEASoft (High Energy Astrophysics Science Archive Research Center).

## Feature Options

| Option | Description | Value Type | Default Value |
|---|---|---|---|
| version | Select the version of HEASoft to install. | string | 6.36 |

## Usage

```json
"features": {
    "ghcr.io/zenless-lab/devcontainer-features/heasoft:1": {
        "version": "6.36"
    }
}
```
